# LogiFlow - Infrastructure
***
>LogiFlow is a logistics management platform that helps teams track shipments, 
> manage warehouses, and automate delivery workflows.
## Getting Started
***

### Prerequisites
- The `infrastructure` directory must be located at the same level as the `backend` and `frontend` directories within the project structure.
- Docker and Docker Compose must be installed and available in the system PATH.
- Required environment configuration files (.env) must be prepared before deployment.
### Installation
```bash
git clone https://github.com/practice-team-lymhqo34/infrastructure.git
cd infrastructure
```

### Running
```bash
docker-compose up --build
```
